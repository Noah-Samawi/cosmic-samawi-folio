# Project conventions

- Services render as six equal cards in a responsive two-row, three-column desktop grid in ServicesSection; localized card copy stays under svc4.* keys to preserve the existing translation namespace.
- Keep the complete-solution section directly after services and before the toolbox so the service offering and its benefits remain adjacent.
- Keep personal homepage copy in the existing DE/EN language context; spoken-language listings do not add interface languages.
- Define accent colors in global CSS and map legacy cyan/blue utilities to the primary token so every existing page stays theme-consistent.
